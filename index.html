Is Even — NPM Package Demo

Powered by is-even-clone — a beginner-friendly npm utility that checks whether a number is even.

🔢 Even / Odd Checker

⚙️ How It Works

This demo installs and calls the is-even-clone npm package directly:

// Install
npm install is-even-clone

// Import
import isEven from 'is-even-clone';

// Use
isEven(4);   // → true
isEven(7);   // → false
isEven(-2);  // → true
isEven(0);   // → true
